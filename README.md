# Blog

A static site generator for [jasoneveleth.com/blog](https://jasoneveleth.com/blog). It's got my custom Markdown dialect (math with KaTeX, code, footnotes, table of contents, and custom `@@div@@` blocks) and renders posts through HTML templates.

To build the site, run `zig build run` and push to github. To preview locally, run `preview-locally.sh`.
